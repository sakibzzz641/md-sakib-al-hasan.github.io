## Built with

- HTML, CSS and vanilla JavaScript (no framework, no build step)
- Content loaded from a single `data.js` file
- Hosted on GitHub Pages

## Project structure

```
├── index.html     # layout, styles and rendering code
├── data.js        # all portfolio content (profile, links, projects, certificates)
└── assets/
    ├── img/       # photo and project images
    ├── cv/        # CV (PDF)
    └── cert/      # certificates
```

## Run locally

Keep `index.html` and `data.js` in the same folder, then open `index.html` in a browser. No install needed.

## Update the content

Edit `data.js` only. Empty link or image fields hide the matching button or image automatically.
